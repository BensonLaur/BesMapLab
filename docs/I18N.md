# 多语言维护

## 使用方式

页面右上角的地球图标打开语言面板；从右向左的界面中位于左上角。选项使用每种语言自己的名称。

- **界面语言**：按钮、投影说明、图层、提示和无障碍名称。
- **地图标注语言**：地区名称、海洋名称、悬停名称和选中地区；默认跟随界面，也可单独选择。
- 语言切换保留投影、中央经线、缩放、选中地区与图层设置。它只更新文案和标签排布。

已提供简体中文、繁体中文、英语、西班牙语、法语、葡萄牙语、阿拉伯语、俄语、德语、意大利语、土耳其语、日语、韩语、印地语、孟加拉语、乌尔都语、印度尼西亚语、越南语，共 18 个选项。

界面语言优先级：有效的 URL `lang` → 浏览器保存的选择 → `navigator.languages` 中首个支持的语言 → 英语。地图标注使用有效的 URL `mapLang` → 保存的选择 → 跟随界面。

例如 `?lang=zh-Hans&mapLang=en` 显示中文界面、英文地名；`?lang=ar&mapLang=follow` 同时切换为阿拉伯语。语言链接只传递语言，尚不包含地图视角。

`zh-TW`、`zh-HK`、`zh-MO` 对应繁体；显式 `Hans` / `Hant` 优先于地区。`en-US`、`pt-BR` 等对应基础语言。手动选择更新本地偏好和当前 URL，避免刷新时旧 URL 覆盖新选择。存储受限时本次访问仍能使用全部语言。

## 资源分层

| 文件 | 内容 |
| --- | --- |
| `locales/manifest.json` | 语言代码、自称、阅读方向、Natural Earth 名称字段 |
| `locales/<语言代码>.json` | 平铺的界面消息键；英语作为运行时回退 |
| `data/name-overrides.json` | 地区代码 → 语言代码 → 项目指定名称 |
| `data/ocean-names.json` | 稳定海洋代码 → 各语言名称 |
| `data/region-labels.json` | 地区代码 → 标签参考点和概览显示资格 |
| `data/region-styles.json` | 颜色引用，与语言无关 |
| `src/i18n.js` | 检测、回退、偏好、页面语言和字典查询 |

地区关联使用当前源数据中唯一的 `ADM0_A3`，不假定所有条目都是 ISO 国家代码。完整与运动简化 TopoJSON 使用相同代码；多语言名称只在独立词典中打包一份。没有把每种语言复制成一套轮廓。

构建读取仓库已有的 Natural Earth `NAME_EN`、`NAME_ZH`、`NAME_ZHT` 等字段。数据版本、来源及文件 SHA-256 仍见 `data/sources.json`，源 GeoJSON 未修改。名称采用：该语言的项目覆盖 → 对应 Natural Earth 名称 → 英语覆盖 / 英语源名。海洋名与界面文案由本项目维护。

按项目所有者要求，`TWN` 在全部语言中采用“台湾 / 台灣 / Taiwan”的对应译名；`CHN` 使用“中国 / China”的短名称。原有简体的俄罗斯、刚果（金）、韩国、美国短名称继续保留，并补充繁体和英语短名称。台湾、香港、澳门继续共用中国的底色，各自保留独立轮廓与点选；此显示规则不改变源几何或分类。迁移还修复了“蒙古”与源名“蒙古国”不一致导致原位置配置未生效的问题，现通过 `MNG` 关联。

## 排版与离线

- `html` 更新 `lang` 和 `dir`；阿拉伯语、乌尔都语采用 RTL。控件使用逻辑方向样式，地图坐标与东西方向保持不变。
- 标注使用自己的语言和方向；中央经线数值采用双向文本隔离，坐标刻度保持 E/W/N/S 表达。
- 字号与描边继续按屏幕像素固定。隐藏的 SVG 测量实际字体成形后的边界，按语言、选中状态和内容缓存，用于标签避让；换语言或字体加载完成时刷新缓存。
- 使用本机字体与系统回退，不下载网络字体。不同系统的字形与可用字体可能有差异。
- 全部词典和几何内嵌进构建后的 `index.html`，切换语言不发起网络请求。

## 校对与增加语言

1. 在 `locales/manifest.json` 添加规范语言代码、自称、阅读方向及源名称字段。
2. 以 `locales/en.json` 的全部键建立新词典，保留 `{value}` 等占位符，不拼接 HTML。
3. 补充五个海洋的译名和项目指定名称；检查该语言的地区名称覆盖。
4. 运行 `npm run build`、`npm run check`、`npm test`，检查长名称、连写文字、RTL、手机与三种投影的截图。
5. 提交源码、词典与更新后的 `index.html`。新增语言时同步检查脚本中的语言数量和能力说明。

当前文案是项目首版翻译，已完成资源完整性、排版和交互验证，尚未经过全部语言的母语使用者校对。欢迎按消息键提交修订；地名来自上游的数据质量也需要持续核对。
