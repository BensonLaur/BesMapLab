# 产品定位与路线

## 定位

一个通过交互了解世界地图的开源项目。帮助对地理好奇的人理解：同一个世界为什么会在地图上呈现出不同的模样。

核心体验：打开地图 → 动手探索 → 产生疑问 → 获得解释 → 分享发现。

## 已完成：地图探索、投影切换与原理介绍

- 水平拖动保持外圈固定并改变中央经线，垂直拖动平移整张地图；斜向拖动同时处理两个方向。
- 点击地区后水平居中，保留纬度；缩放以鼠标为锚点。
- SVG 轮廓和文字，浏览器本地运行，可分享单文件 HTML。
- Robinson、Equal Earth、Mercator 三种投影切换，保留选中地区、中央经线、缩放与地理参考位置。
- 固定字号标签、动态经纬度刻度和坐标读数。
- 六项独立图层开关及浏览器本地偏好保存。
- 18 个语言选项，界面与地图名称可同步或分别选择；支持 RTL、语言链接与离线切换。
- 三种投影的绘制原理、保留与改变的性质、用途、真实投影经纬网示意和参考资料；阅读栏按需打开，支持 18 种界面语言和手机布局。

## 后续候选（未实现，无发布日程承诺）

1. **投影比较扩展**：更多投影和并排对照，帮助比较每种投影保留和改变的性质。
2. **变形可视化**：用可直接观察的形状或面积对照，进一步解释投影的取舍；优先补充有实质价值的内容。
3. **面积实验**：地区真实面积比较；明确数据口径，避免把屏幕像素面积误当真实面积。
4. **语言质量**：母语文案校对与上游地名核对；补充更多平台的字体检查。
5. **分享发现**：保存投影、中央经线、缩放、选中地区和语言，使打开链接的人能继续探索。
6. **地球仪对照**：展示球面与平面投影的关系。

## 设计原则

- 每项交互应对应一个可解释的地理问题。
- 使用简短、随操作出现的解释；为进一步阅读提供来源。
- 明确投影的取舍，不将某个投影描述为所有方面都准确。
- 保持离线体验和轻量部署能力。
- 开源与自愿打赏可以共存，打赏不改变 MIT 许可。
