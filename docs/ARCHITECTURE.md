# 实现说明

## 数据到画面

```text
Natural Earth 经纬度多边形、海上界线指示线 + 标签位置
  → 修正 D3 球面环方向
  → 共享边界 TopoJSON（完整 / 运动简化）
  → 经纬度旋转、反子午线裁剪、所选投影
  → SVG path 与 text
```

`scripts/build.cjs` 使用仓库内固定版本的 D3 和 TopoJSON 工具构建页面。没有网络下载步骤，构建结果可复现。

## 水平旋转与垂直平移

每种投影的比例和屏幕位置在选择该投影时固定。旋转交互改变 `projection.rotate([-centralLongitude, 0, 0])`，每帧重算轮廓与标签。D3 处理跨左右接缝的多边形裁剪。

国家/地区的参考点经度用于水平居中，它不一定是严格的几何质心。点击时按最短经度差插值，持续约 900 毫秒；减少动画偏好启用时立即定位。同时使用相同缓动，将视口中心的投影横坐标移向 `projection.translate()[0]`，让中央经线回到可见地图区域的水平中央，避免鼠标位置缩放或 Shift 平移后将选中地区转出屏幕。动画保持缩放和 `viewBox.y` 不变；每帧按当前视口宽度计算 `viewBox.x`，兼容动画中调整窗口大小。新的滚轮或按钮缩放会中断居中动画，保留当时的旋转与平移位置，再执行缩放。

纯经度旋转保持纬度和外圈不变。Robinson 不等积，改变中央经线不会消除它的面积失真。

普通鼠标拖动或单指触控同时分解为两个方向：横向沿用拖动起点纬度下的每度投影距离来计算中央经线；纵向按屏幕像素换算为 `viewBox.y` 的位移。垂直拖动移动整个投影画面，包括外圈、轮廓、地名与经纬网，地理纬度和投影形状保持不变。斜向拖动在同一帧提交视图平移和经度旋转；松开时也提交尚未绘制的视图位置，避免丢失最后一次移动。

Shift + 拖动继续在两个方向自由平移。平移后重新布局地名、经纬度刻度与坐标读数；固定界面控件保持原位。“恢复全图”同时恢复视图位置、缩放与中央经线。

触控开始时浏览器可能先由地区路径隐式捕获触点；拖动后由视口接管。只处理视口自身丢失捕获的事件，忽略子元素捕获转移时冒泡的通知，避免手势在第一次移动后提前结束。

## 三种投影与切换

- `src/projections.js` 单独维护投影定义及纬度范围，使用内嵌的 `geoRobinson`、`geoEqualEarth`、`geoMercator`；投影说明保存在界面词典，地理数据、名称及配色覆盖共用，不随投影改变。
- 三种投影使用同一个投影适配区域；视口宽度再按实际世界轮廓计算，避免方形 Mercator 在竖屏中因沿用椭圆全图的横向留白而过小。Mercator 保留 D3 的方形裁剪，纬度上限为 `atan(sinh(π))`（约 85.051°），避免试图把两极的无限坐标放入全图。
- 切换先停止动画和当前手势，再重建投影、路径生成器、世界外圈及裁剪区域，重绘所有地图图层。保留选中地区、中央经线和缩放比例；将视口中心反投影为经纬度，再投影到新坐标，避免把旧投影的 x/y 直接沿用。
- 地理参考点在地图外时回退到选中地区或中央经线赤道点；Mercator 对超出范围的参考纬度做限幅。重置视图仍保留当前投影和图层设置。
- 投影 ID 使用 `besmaplab.projection.v1` 独立保存，只接受定义中的合法值。存储不可用时仍可切换；不保存拖动轨迹或其他使用记录。
- 浏览器回归检查投影切换的地理参考位置、中央经线、选择与偏好保持，以及 Equal Earth 等面积和 Mercator 高纬放大、极区裁剪。

## 性能与清晰度

- 动画使用简化后的共享边界，停止后恢复完整细节。
- 共享弧段简化可避免相邻地区的边界独立处理后产生缝隙。
- 海上界线指示和中国补充线保留各自的开放线段，旋转时使用完整几何并通过相同投影和反子午线裁剪；不拼接为海域面，线宽保持屏幕像素大小。
- 普通海上界线使用低对比度细虚线，中国补充线保留原始断续形态；透明度随实际屏幕比例平滑提高，让概览和窄屏减少碎线干扰，放大时能看清细节。样式不改变源线段的位置和走向。
- 缩放调整 SVG `viewBox`，不放大栅格截图。
- 地区和海洋标签按屏幕像素固定字号；每次缩放或窗口尺寸改变时换算为 SVG 单位，文字描边也同步补偿。
- 低于 150% 时使用概览稀疏标签集；从 150% 起，全部国家/地区名称参与显示候选，无需先点选。使用 SVG 测量实际字体成形后的屏幕文字框，添加间距后避让重叠；测量按内容、语言和选中状态缓存。选中地区优先，其次海洋名称及源数据的标签等级。空间足够且标签参考点位于视口内时显示，缩回概览后恢复稀疏标签。

## 经纬度与显示图层

- 经纬网按实际屏幕比例选择间隔，只生成当前可见的经纬度范围；横向旋转使用围绕中央经线展开的经度范围，再交给 D3 裁剪，避免跨 180° 时遗漏刻度。
- 当前三种投影的纬度均不受经度旋转影响，横坐标与相对经度成正比；经纬网计算利用这一约束。经度刻度放在地图上缘或视口上缘附近，纬度刻度沿左侧；切换投影、缩放、平移和旋转时同时更新数字、刻度线与网格。刻度保持 10 屏幕像素，并避让界面控件。
- 纬线保持等纬度采样，不能仅用两个端点让 D3 插值成大圆弧。屏幕视图不再与地图相交时清空网格和刻度。
- 指针或触点坐标通过当前投影反算；先用世界轮廓检查点是否在图内，轮廓外不显示伪坐标。地区名称与海洋名称会为经纬刻度和界面控件让出空间。
- 图层面板独立控制六项可选内容，不改变地理数据和地区点选。名称关闭后不参与标签避让，重新开启时会按当前视图重新布局。
- `besmaplab.layers.v1` 仅在本地存储六个布尔偏好；读取时忽略未知键和非布尔值。读取或保存失败均不会阻断绘图，并提示设置仅在本次访问有效。视图重置保留偏好，面板“恢复默认”只重置图层。
- 面板为非模态控件，原生开关支持键盘和触控；关闭按钮和 Escape 返回触发按钮，点击面板外关闭，窄屏或矮屏内可滚动访问全部选项。

## 数据、语言和许可

源数据保留 Natural Earth 名称字段，构建提取 18 个语言选项所需字段并应用 `data/name-overrides.json` 的项目显示覆盖。标签位置、配色与名称通过唯一地区代码关联，分别维护。`TWN` 在各语言中显示为“台湾 / 台灣 / Taiwan”的对应译名；台湾、香港、澳门引用 `CHN` 的底色，各自保留独立轮廓和点选对象。此覆盖不改动上游几何及分类字段。

`src/i18n.js` 管理语言检测、英语回退、本地偏好及界面翻译。地图标注默认跟随界面，也可独立选择；UI 与标注的 `lang` / `dir` 分别设置，几何和经纬度方向不会因 RTL 改变。全部词典在构建时内嵌，运行时不请求翻译或字体。资源结构和维护方式见 [I18N.md](I18N.md)。

`data/sources.json` 记录第三方与地理文件的来源及当前文件哈希。地理文件是现有原型的快照，不声称其与上游 master 永远一致。换行统一为 CRLF，因此哈希针对仓库中的文件。

页面内嵌运行时库和完整许可声明；`LICENSES/` 保存上游许可原文。地理数据的公有领域状态独立于项目原创代码的 MIT 许可。
