# 实现说明

## 数据到画面

```text
Natural Earth 经纬度多边形 + 标签位置
  → 修正 D3 球面环方向
  → 共享边界 TopoJSON（完整 / 运动简化）
  → 经纬度旋转、反子午线裁剪、Robinson 投影
  → SVG path 与 text
```

`scripts/build.cjs` 使用仓库内固定版本的 D3 和 TopoJSON 工具构建页面。没有网络下载步骤，构建结果可复现。

## 外圈固定的水平旋转

投影的比例和屏幕位置初始化后固定。交互改变 `projection.rotate([-centralLongitude, 0, 0])`，每帧重算轮廓与标签。D3 处理跨左右接缝的多边形裁剪。

国家/地区的参考点经度用于水平居中，它不一定是严格的几何质心。点击时按最短经度差插值，持续约 900 毫秒；减少动画偏好启用时立即定位。

纯经度旋转保持纬度和外圈不变。Robinson 不等积，改变中央经线不会消除它的面积失真。

## 性能与清晰度

- 动画使用简化后的共享边界，停止后恢复完整细节。
- 共享弧段简化可避免相邻地区的边界独立处理后产生缝隙。
- 缩放调整 SVG `viewBox`，不放大栅格截图。
- 概览只显示稀疏标签，选中地区始终显示标签；完整标签布局仍是后续工作。

## 数据、语言和许可

源数据保留 Natural Earth 名称字段，当前构建选择中文名称及少量显示覆盖。多语言尚未实现，未来应通过稳定代码关联语言资源。

`data/sources.json` 记录第三方与地理文件的来源及当前文件哈希。地理文件是现有原型的快照，不声称其与上游 master 永远一致。换行统一为 CRLF，因此哈希针对仓库中的文件。

页面内嵌运行时库和完整许可声明；`LICENSES/` 保存上游许可原文。地理数据的公有领域状态独立于项目原创代码的 MIT 许可。
